# 10-16-agent-rework-lens 项目计划总览

**项目**：AI 代码"重复造轮子 + 返工"体检器（扫描本机 Claude Code / Codex 会话日志，输出返工文件 Top 与"新建 vs 复用"指标；纯本地 Python CLI）
**方法论**：ai-tool-project-sprint（数据先行 + 合成会话植入真值 + 确定性计数指标 + 口径一处定义 + 纯本地零上传）
**项目系列**：同系列新题（**不参赛**，发 GitHub 公开仓库；前作名称与业务领域按脱敏纪律不入公开仓，见「决策记录」品牌隔离项）
**命名约定**：本地目录 `10-16-agent-rework-lens`（`10-16`=2026-10-16 日期标签）；**GitHub 仓库名 = `agent-rework-lens`（纯净名，去日期前缀）**，沿用系列惯例 `yuluo554/<kebab-name>`；署名 `yuluo554`（LICENSE / pyproject 一致）。
**定位宣言（v1）**：扫描本地 Claude Code / Codex 会话日志，回答——**这次会话里 agent 有几成 Edit/Write 是在重写项目里已存在的工具函数？哪些文件被反复改回（返工）？** 给出可证伪的硬指标：纯本地、零模型、零上传。LLM 聊天拿不到你本机的**版本快照链**与**跨会话持久基线**，所以它给不了这个答案。

## 开工前预检结论（对应 ai-tool-topic-definer 验收门）

- **版本素材预检（①⑥）**：本题**不以"版本化规则包 / 双标尺"作亮点**——规则是阈值（一处定义），不涉多版本对照，故①⑥不适用；亮点锚在"**会话日志版本快照链**"这一真实、可区分的本地素材上（✅ 本机 68 个快照 / 9 会话实测），非换标签充数。
- **数据底座可获取性预检（②）**：三条本机源 + 官方文档**全部当场实测**（✅ 见 data/README §二），无"待获取作底座"项。
- **可参数化预检（⑤）**：不适用（无标准条文类底座）。
- **交付物可达性预检（③）**：纯本地 Python CLI，零网络依赖、零随包大文件 → 依赖可达性无风险；报告与基准全部本地生成。
- **口径一致性预检（④）**：阈值**一处定义**（配置文件 / 常量模块），报告 / 基准 / README 一律引用；**禁止在文档或报告里手写第二份阈值口径**。
- **映射预检（⑧）**：五个首期模块逐项映射到本机实测数据源（解析→jsonl/rollout；返工→file-history；指标→IR 事件；报告→引擎结果；基准→合成会话生成器），无"列了但无底座"的模块。
- **结构核对预检（⑦）**：题面引用的字段名（`trackedFileBackups` / `backupFileName` / `version` / `tool_use` / `usage` / `token_count` / `total_token_usage`）**均来自本机实测样本**，非凭印象；官方文档字段（`session_id` / `transcript_path` / `cwd`）已直连核到。
- **数字承诺为口径式**：题面不写会漂移的硬数字；数据源条数为**本机实测快照**（附基准日 2026-10-15），非交付承诺。
