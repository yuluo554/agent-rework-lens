## 1. `config.py` — 阈值/口径唯一口径（★ K1）

- **数值阈值**（含义如下；**数值只在此文件出现一次**，文档/报告/基准/生成器一律引用）：
  - `REWORK_MIN_VERSIONS`：返工判定——同一文件版本链出现 ≥ N 个版本；
  - `REWORK_MIN_EDITS`：返工判定——单会话内被 Edit ≥ M 次；
  - `DUP_MATCH_THRESHOLD`：粗匹配高相似度阈值（`difflib` ratio ∈ [0,1]）。
  - 初始值在 M0 落定，**M3 由基准校准后定稿**（校准也是改这一处；变更记决策记录）。
- **口径定义集合**（同属"一处定义"）：
  - `READ_EVENT_KINDS` / `WRITE_EVENT_KINDS`：Read:Edit 比的分子/分母口径集合；
  - `SYMBOL_PREFIX_TOKENS` / `SYMBOL_SUFFIX_TOKENS`：符号名归一化前后缀词表（如 `get`/`_helper` 族）；
  - `SUPPORTED_SYMBOL_LANGUAGES`：首期 `{"python"}`（其他语言显式不支持）。
- **路径发现口径**：`DEFAULT_CLAUDE_HOME="~/.claude"`、`DEFAULT_CODEX_HOME="~/.codex"`、环境变量名 `ARL_CLAUDE_HOME` / `ARL_CODEX_HOME`。
- **守门**：`tests/test_config.py` 用 AST 断言——模块级阈值名**只允许**出现在 `config.py`；集合为 `frozenset`（防运行期被改）。
- **禁止**：任何模块/文档手写第二份数值（文档只写"见 config.py 常量名"）。

## 2. `stdio.py` — 编码护栏（★ K10）

- `_ensure_utf8_stdio()`：对 `sys.stdout` / `sys.stderr` 逐个检查——
  1. 取 `stream.encoding`（无则视为 `ascii`）；
  2. 用样例串（含中文与符号）`encode()` 探针：**能编码 → 不动**（中文控制台 cp936 保持原样，显示正常）；
  3. 不能编码且流有 `reconfigure` → `reconfigure(encoding="utf-8", errors="backslashreplace")`；
  4. 无 `reconfigure`（如被重定向为 StringIO）→ 静默跳过（不抛错）。
- **调用点**：`cli.main()` 第一行；**M1 起每个 `tools/` 脚本第一行**（新增脚本必须挂，K10 硬约束）。
- **回归**：`tests/test_stdio.py` 用 `TextIOWrapper(BytesIO(), encoding="cp1252", errors="strict")` 复现 cp1252 崩溃场景 → 护栏后中文正常写出；utf-8 流不被动过。

## 3. `exitcodes.py` — 退出码契约（★ K2）

| 码 | 常量 | 语义 |
|---|---|---|
| 0 | `OK` | 成功 |
| 1 | `INTERNAL_ERROR` | 未预期内部错误（Python 未捕获异常默认路径） |
| 2 | `USAGE_ERROR` | 用法错误 / 未知命令 / 坏参数（argparse 默认） |
| 3 | `NO_SOURCES` | **未发现可分析日志**（明确提示，不伪造空报告） |
| 4 | `STAGE_NOT_READY` | **骨架期临时态**：功能未到该里程碑。M2 起逐项退役，退役时同步删常量、改测试、更新 K2 |

- 锁测：`tests/test_cli.py` 覆盖 0/2/3/4 真实触发；常量唯一性在 `tests/test_exitcodes.py`。

## 4. `discovery.py` — 路径自适应发现（FR-1）

- **API**：
  - `discover_sources(claude_home=None, codex_home=None, source_filter="auto") -> DiscoveryResult`
  - `DiscoveryResult.locations: Tuple[SourceLocation, ...]`、`.missing: Tuple[MissingSource, ...]`、`.total_files: int`
  - `SourceLocation(kind, root, files)`；`kind ∈ {"claude_sessions","claude_file_history","codex_sessions"}`
- **优先级**：显式参数 > 环境变量（`ARL_CLAUDE_HOME`/`ARL_CODEX_HOME`）> 默认位置（`~/.claude`、`~/.codex`）；
- **发现规则**：
  - Claude 会话：`<claude_home>/projects/**/*.jsonl` **递归**（实测有嵌套），空目录跳过，非 `.jsonl` 过滤；
  - Claude 版本快照：`<claude_home>/file-history/<session>/<hash>@v<N>`（按文件计数）；
  - Codex 会话：`<codex_home>/sessions/**/*.jsonl` 递归；
- **输出确定性**：结果按 `kind`、路径排序；计数为文件数快照；
- **缺源语义**：找不到 → 进 `missing`（带查找过的位置说明）；**绝不伪造空报告**；
- 全部用 `pathlib` + `expanduser`，**不硬编码用户名**（data/README §二 声明）。

## 5. 解析层 `parsers/`（M2 实现；M0 仅 common 🟢）

- `common.py`（🟢）：`iter_jsonl_lines(path) -> Iterator[tuple[int, Optional[dict], Optional[str]]]`（行号、解析结果、错误信息）——**坏行只计数不中断**；
- `claude_code.py` / `codex.py`（🟡 M2）：
  - 接口：`parse_claude_session(path) -> SessionIR`、`parse_codex_session(path) -> SessionIR`；
  - **字段策略表**：实现时必须逐字段对照 data/README §二 的核对状态列——**核对状态 ≠ ✅ 的字段不得进入计算路径**（落 `unknown`/跳过并计入 `ParseNote`）；
  - M0 护栏：函数体抛 `StageNotReady`（脚手架异常），`scan` 捕获后提示"M1 数据核对 → M2 启用"并以退出码 4 退出；
  - M2 起每个解析器配**合成样例回归**；同一输入双跑 → `to_json()` 逐字节一致。

## 6. IR `ir.py`（🟢 schema v1，字段表见 03 §五）

- 全部 `frozen=True` dataclass；事件序列用 `tuple`；`to_json()` canonical（`sort_keys=True`、`ensure_ascii=False`、`indent=2`、末尾 LF）；
- `ir_version: int = 1` 显式携带（格式演进时 bump + 决策记录）；
- 辅助：`make_note(code, message, count)`；IR 相等性 = 结构相等（测试用）。

## 7. 引擎层 `engine/`（M3 实现算法；M0 定义类型 🟢 + 护栏）

### 7.1 `rework.py`（FR-6/7）
- 输入：`SessionIR` 的 edit/write/multiedit 事件 + `FileVersionChain` 列表（来自 file-history 实读，M2 产出）；
- 输出：`ReworkFinding(file_path, session_id, version_count, edit_count, first_edit_seq, last_edit_seq, span_seconds, verdict, reasons)`；
  - `verdict ∈ {"rework", "not_rework", "insufficient_data"}`；`reasons` 为元组（如 `"versions>=N"` / `"edits>=M"`）；
- **判定语义（口径）**：
  1. 任一条件成立（版本数 ≥ N 或 Edit 次数 ≥ M）→ `rework`；
  2. 两条件都不成立且**版本链缺失** → `insufficient_data`（**不得**由 Edit 次数反推版本链，K4）；
  3. 两条件都不成立且版本链存在 → `not_rework`；
- 时间跨度 = 首末编辑时间戳差（时间戳缺失 → `None` 并在报告注明）；
- `analyze_rework(...)` M0 抛 `StageNotReady`。

### 7.2 `metrics.py`（FR-8）
- `Read:Edit 比`：分子 = `READ_EVENT_KINDS` 计数；分母 = `WRITE_EVENT_KINDS` 计数（两者均在 config 单点）；
  - 分母为 0 → `read_edit_ratio = None`，报告显示"未定义（无写操作）"，**不填 0/不填 inf**；
- 输出 `SessionMetrics(session_id, reads, writes, writes_by_kind, read_edit_ratio)`。

### 7.3 `symbols.py`（FR-9）
- `extract_defined_symbols(text, language="python") -> Tuple[Symbol, ...]`：`Symbol(name, kind ∈ {"function","class"}, line_in_payload)`；
- 首期仅 Python（`def` / `class` 正则 + 合法性校验）；`language ∉ SUPPORTED_SYMBOL_LANGUAGES` → 显式"未支持"（不猜测）；
- 项目已有符号清单：对"会话中 Read 过/已存在"的文件做同函数提取（M3 接 IR 的 read 事件 + 路径存在性检查）。

### 7.4 粗匹配（M3；口径定义在 M0 已冻结）
- 归一化（`normalize_symbol_name`）：① 转小写；② `-` → `_`；③ 去首尾 `_`；④ 按 `_` 切分，**首 token** 命中 `SYMBOL_PREFIX_TOKENS` 或 **尾 token** 命中 `SYMBOL_SUFFIX_TOKENS` → 剔除（可迭代）；⑤ 剩余 token 拼接（去分隔符）；
- 匹配：归一化后**精确相等** → 候选（`reason="normalized_exact"`）；否则 `difflib.SequenceMatcher.ratio() ≥ DUP_MATCH_THRESHOLD` → 候选（`reason="high_similarity"`，附 ratio）；
- 输出 `DupCandidate(new_symbol, existing_symbol, match_reason, similarity, new_evidence, existing_evidence)`；
- **披露制**：输出任何候选的地方（报告/CLI）必须带 `DUP_DISCLOSURE` 常量文本"粗匹配 ≠ 确认重复"（K5，测试锁）。

## 8. 报告层 `report/`（🟢 最小可用；M4/M5 充实）

- `model.py`：`ReportModel(meta, rework_findings, dup_candidates, session_metrics, notes)`；`ReportMeta(title, tool_name, tool_version, source_summary, thresholds_note)`；
- `markdown.py` / `html.py`：`render_markdown(model) -> str`、`render_html(model) -> str`；
- **渲染契约（K6）**：
  1. 只渲染模型数据，零判定逻辑；渲染器**不读时钟/环境**（时间戳作为入参）；
  2. HTML **零外链**（内联样式；无 `http(s)://`、无 `<script src>`、无 CDN）——测试断言；
  3. 同一模型两次渲染**逐字节一致**；
  4. 空节显示"无数据（未启用/未发现）"，**不得**显示"一切正常"这类假结论；
  5. 重复候选节必须含 `DUP_DISCLOSURE`；
  6. 阈值展示取自 config 运行时值（经模型传入），报告不写死数字。
- **证据锚点规范**：`(会话 id, 源文件行号, 版本快照文件名 <hash>@vN)` 三元组；报告每条结论至少持一个锚点。

## 9. 基准套件 `benchmark/` + `tools/`（M1 数据 / M4 runner）

- 数据（M1，详见 [05-数据计划.md](05-数据计划.md)）：`data/synthetic/samples/<case-id>/`（session.jsonl + file-history/ + truth.json）+ `manifest.json`；
- `tools/gen_synthetic.py`（M1）：确定性生成器（自研 RNG、禁 stdlib random/禁时钟）；`--check` 再生成位级一致；
- `benchmark/runner.py`（M4）：`run_bench(data_dir) -> BenchResult`——
  - 读 manifest 覆盖率门槛（**数值只在下发数据里，不在代码里**）→ 不达标 → 退出码 1 + 明确未达标清单；
  - 逐样例跑解析→引擎→与 truth 对账（检测率/误报率/锚点可溯源率）；
  - **可证伪探活**：注入缺陷（如把返工判定强行置 False）→ 基准必须报未达标（M4 落档验证命令与结果）；
  - "未启用"套件不冒充通过（空分母 → `not_enabled` + 说明 + 退出码 1 的探活保护）。

## 12. `selftest.py`（🟢）

自检项（任一 FAIL → 退出码 1）：
1. 版本一致性：`__version__` 与已安装分发元数据一致（未安装 → 标 SKIP 不标 FAIL）；
2. 口径存在性：config 阈值与集合存在且类型/取值域合法；
3. 退出码映射：常量齐备且互异；
4. 编码护栏：`_ensure_utf8_stdio` 可调用且探针逻辑自洽；
5. 发现探测：在本机跑一次发现（不要求有源，**不得抛异常**）。
