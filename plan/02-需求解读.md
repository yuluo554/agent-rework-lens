## 三、边界与非目标（执行口径）

复核 01 §六，逐条落为可执行约束：

1. **不做代码质量全量扫描**（lint / 风格 / bug）——只做 agent 返工与重复这一交叉点；
2. **不修改用户代码**——只读分析（读日志、读快照、读源码提取符号）；绝不写回、绝不自动修复；
3. **隐私红线**：零上传、零遥测、不联网；真实会话日志**一律不入仓**（`.gitignore` 兜底 + 提交前审计）；
4. **不做 AI 评分**：全部指标为确定性计数与结构性事实，无模型 judgement；
5. **首期不做完整克隆检测**——只做符号名**粗匹配**（候选级信号，报告显式披露"≠ 确认重复"）；
6. **不承诺跨机器可比**：解析以"本机实测字段核对记录"为依据；未核对字段**不进计算路径**（落 unknown）；
7. **无 GUI、无 exe 打包承诺**：纯 CLI，Python ≥ 3.8 环境可直接运行；
8. **不做服务端 / 团队聚合 / 看板**（与隐私红线冲突，属扩展）；
9. **品牌隔离**：不复制姊妹项目代码；公开文档不提其余项目领域。

## 四、用户旅程（Canonical Path）

1. **安装**：`pip install -e ".[dev]"`（零运行时第三方依赖；将来可 pipx）；
2. **发现**：`arl sources` → 列出本机发现的日志源（Claude / Codex / file-history）与文件数；未发现 → 给出检查项与路径线索；
3. **分析**：`arl scan` → 全链路（解析 → 返工检测 → 指标 → 报告），生成本地报告；
4. **回溯**：报告每条结论带**证据锚点**（会话 id / 源文件行号 / 版本快照文件名）→ 用户可自行复核；
5. **复现评测**：`arl bench` → 合成基准跑通（检测率 / 误报率口径见 README）；
6. **隐私确认**：全过程无网络请求；报告只落用户本地。

> M0 骨架期现状（诚实口径）：步骤 1–2 已可用；步骤 3 以明确的"阶段未就绪"提示与退出码 4 拦截（不产出假报告）；步骤 4–5 未启用。

## 五、验收口径

### 5.1 对照评分标准（40/20/20/20）
逐维对策与证据指针见 [07-交付对标与决策记录.md](07-交付对标与决策记录.md) §二。

### 5.2 内部硬门（acceptance gates）

- **双源解析正确性**：合成样例逐例对账；本机真实样本只读抽验（结论进 data/README，原始文本不入仓）；
- **返工检测与基准一致**：合成真值对账（检测率 / 误报率口径进 README，达标线随 manifest 下发）；
- **证据锚点可溯源**：基准中每条锚点可回溯（行号 / 版本文件名存在且指向正确）；
- **口径单点**：改 `config.py` 一处 → 引擎 / 报告 / 基准 / 生成器全链路同变（测试断言）；
- **失败路径全显式**：缺源 / 坏行 / 缺版本链 / 除零 / 未支持语言均有明确语义与测试；
- **干净环境**：新目录 clone + 全新 venv 按 README 逐条一次跑通（M5 执行并留档）；
- **测试全绿**：本机双解释器（3.8 + 3.12）全量；推送后 CI 三腿——**未推送期间一律记"本地等价校验（未接远端，CI 待首推验证）"**。
