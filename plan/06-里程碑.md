# 06 · 里程碑（M0–M7，M0 定稿）

**上游**：[00-README总览.md](00-README总览.md)、[02](02-需求解读.md)–[05-数据计划.md](05-数据计划.md)
**状态**：✅ M0 定稿（2026-10-15）
**通用纪律**（每棒生效）：
1. **HANDOFF 硬约束**：每个里程碑 DoD 达成并验证后，**必须在本对话内写完下一阶段 `plan/HANDOFF-M<next>.md`** 才允许结束对话（六节：进度+证据 / 待办 / K 口径清单 / 环境坑 / DoD checklist / 命令速查）；收尾顺序固定 = DoD 验证 → plan/00·06·07 状态回写 → 写 HANDOFF → commit →（有远端则 push 等 CI 绿）；
2. **诚实口径**：未推送 = 未跑 CI，一律写"本地等价校验（未接远端，CI 待首推验证）"并列出**可指认的替代证据**；不可本机实跑的通路显式标"待首推验证"；
3. **每次收尾复跑基线**防回退（M4 起：合成基准 + 测试全量双跑）；
4. **口径变更流程**：凡"动了会打挂测试"的改动（K 清单项）→ 同步改 测试 + 报告 + 生成器 + 文档，并登记 [07](07-交付对标与决策记录.md) 决策记录；
5. **一里程碑一对话**：续接一律读 `plan/HANDOFF-M<n>.md`。
