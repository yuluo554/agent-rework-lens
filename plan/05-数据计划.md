## 一、数据先行原则（复核）

1. **未挂数据格式核对不得落库 / 不得进入指标计算路径**——凡解析某字段，先以本机实测样本核对存在性与语义，核对记录进 data/README.md；
2. **基准一律合成**：零真实项目、零真实路径、零真实用户名；真实会话日志**绝不入仓**；
3. **数值口径单点**：阈值只在 `config.py`；数据集只承载"覆盖度门槛数值"（manifest）与冻结字节；
4. **冻结即契约**：被台账登记 sha256 的合成快照为冻结构建，禁手改；改动走生成器整目录重生成。

## 四、合成会话生成器规范（`tools/gen_synthetic.py`，M1）

### 4.1 确定性纪律（硬约束）
- **禁 stdlib `random`**、禁 `set` 迭代序、**禁系统时钟**——自研确定性 RNG（splitmix64 形态），固定 seed；
- 所有时间戳为**固定常量**（写成样例的一部分，不取 now）；
- 输出编码 UTF-8（无 BOM）、**LF 行尾**、字段序固定；
- **两次运行逐字节一致**；提供 `--check`（重生成 vs 现有冻结件逐字节比对），并配 pytest 守门。

### 4.2 样本类型矩阵（每类 ≥ manifest 门槛例数）
- **异常类型**：
  1. `rework`（版本链 ≥N 或 Edit ≥M，真值标 `rework` + 命中理由）；
  2. `duplicate`（新写符号与项目已有符号命中粗匹配，真值标候选对 + 归一化理由）；**两级匹配均需入 bench 对账**——`normalized_exact` 与 `high_similarity` 各至少一例（审计修复补齐后者）；
  3. `normal`（写行为正常，两条判据均不命中 → `not_rework` 且无候选）；
- **边界类型**：
  4. `missing_chain`（有写行为但无 file-history → `insufficient_data`）；
  5. `single_edit`（单次编辑、v1 语义下的最小链）；
  6. `threshold_exact`（恰好卡阈值：版本数 = N 或 Edit 数 = M，判 **应命中**）；
  7. `near_miss`（符号名近但不重：相似度低于阈值 → **不应命中**，反向样例）。
- **门槛数值只在 manifest**（`coverage.min_count_by_type` 等键；生成器与 runner 读 manifest；文档只写"每类有最低覆盖项"）。

### 4.3 植入真值语义
- 真值 = **生成时同步标注**（程序化，非人工事后补写）；
- `truth.json` 字段（草案，M1 定稿）：
  - `expected_rework`: `[{file, reason: "versions"|"edits"|"both", min_versions, edit_count}]`；
  - `expected_dup_candidates`: `[{new_symbol, existing_symbol, reason: "normalized_exact"|"high_similarity"}]`；
  - `expected_normal`: `[{file, edit_count}]`；
  - `expect_status`: 该样例整体期望（`rework_hit` / `insufficient_data` / `not_rework` …）；
  - `also_expect`：同一注入隐含的其余结论（如"命中返工"同时隐含"Edit 计数 ≥ M"），供全量对账；
- **互斥检查**：同一文件两处注入不得打架（生成器内断言）；先清旧行再写新行。

### 4.4 假名白名单（登记制）
- 假项目名：`demo-project-alpha` / `demo-project-beta`（前缀 `demo-` 受控）；
- 假路径：`/demo/alpha/...`（POSIX 形态）与 `D:\demo\beta\...`（Windows 形态）；
- 假 session id：`00000000-0000-4000-8000-0000000000NN`；
- 假用户名 / 主机名：`demo-user` / `demo-host`；
- 所有白名单词表登记进 manifest；**新增假名先登记后使用**。
